# Chrome extension installation

1. In ChromeOS Chrome, open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Choose **Load unpacked** and select this `chrome-extension` directory. If ChromeOS cannot select a Linux directory, copy it to **Downloads** with the Files app first.
4. Pin **DRI Course Completion Checker**.
5. Sign in normally to the Delivery Readiness Portal and Google Skills for Partners in Chrome.
6. Open the Readiness Portal's **Manage DRI Attribute** page.
7. Select the extension and click **Check courses**.
8. Reopen the extension after the tabs finish, review results, and choose **Download Markdown**.

The extension uses only the two portal origins plus Chrome local storage. It does not read or store passwords or cookie values.
